# 🎮 НейроБарбоскины — Сайт для стрима

Сайт для просмотра YouTube-стрима с чатом, онлайн-статусом и командой смены темы.

## ✨ Особенности

- 🎬 **YouTube-плеер** — встроенный плеер с автозапуском
- 💬 **Чат в реальном времени** — на Socket.IO, без аккаунтов
- 👥 **Счётчик онлайн** — показывает количество зрителей
- 🎯 **Команда `/тема`** — меняет тему стрима (например: `/тема Дружок и Гена обсуждают пельмени`)
- ⚠️ **Фоллбек при ошибках** — если YouTube не загрузился за 15 сек: *"Стрим лёг, или загружается или сбои"*
- 🌙 **Тёмная тема** с жёлтыми акцентами
- 📱 **Адаптивный дизайн** — работает на мобильных

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
python run.py
```
Или напрямую:
```bash
python app.py
```

### 3. Открытие в браузере
```
http://localhost:8000
```

| Команда | Описание |
|---------|----------|
| `/тема Текст` | Сменить тему стрима (видно всем) |

*Пример: `/тема Дружок и Гена обсуждают пельмени`*

## ⚙️ Настройка

### Сменить YouTube-видео
В `templates/index.html` найдите:
```javascript
const YOUTUBE_VIDEO_ID = 'J46Cc7D-Wqg';
```
Замените на ID нужного видео.

### Изменить порт
В `app.py`:
```python
socketio.run(app, host='0.0.0.0', port=8000, ...)
```

### Таймаут загрузки стрима
В `templates/index.html`:
```javascript
const STREAM_LOAD_TIMEOUT = 15000; // мс
```

## 🛠 Технологии

- **Backend**: Flask + Flask-SocketIO + eventlet
- **Frontend**: Vanilla JS + CSS Grid + CSS Variables
- **Real-time**: WebSocket (Socket.IO)
- **Fonts**: JetBrains Mono + Rubik (Google Fonts)
